# 🎠 my-carousel

纯前端轮播组件练习 —— 从「HTML 写死三张图」改成「数据驱动渲染」。

## 为什么这么写
把内容和视图分开：slides 放数组，JS 循环生成 DOM。
以后换成 Astro / React / AEM HTL，只是换语法，
「数据 → 模板 → 页面」这个思路不变。

## 跑起来
双击 `index.html` 就行，不用装任何东西。
